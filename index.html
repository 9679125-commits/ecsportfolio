3. Action Tank Game & Object Engine

Arrays / ArrayLists Polymorphism Inheritance Collision Matrices

A complex top-down battle application leveraging advanced data containers and structural object hierarchies. All entities—including stationary block structures, dynamic bomb hazard entities, and medical health items—derive from a base entity model using inheritance.

Through polymorphism, a single unified global game engine tick sequence iterates over an ArrayList containing all entities on the map, calling their specific overridden update logic structures automatically.
