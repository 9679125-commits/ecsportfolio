My Projects

Welcome to my portfolio! Below are some of the programming projects I have developed, demonstrating Object-Oriented Programming (OOP) concepts and interactive design.

1. TankGame

OOP Implementation & Logic:

TankGame is a 2D top-down game built using Object-Oriented Programming principles. It utilizes a core Tank class to instantiate the player's object, tracking dynamic instance variables like health (initialized at 100) and positional coordinates. The game loop handles intense game logic, managing user interaction via keyboard inputs for movement while handling collision detection. An ArrayList is used to dynamically manage active Bomb objects spawning on the screen. Encapsulation ensures that vital stats like player health are protected and modified safely using specialized methods when a collision with an obstacle or a bomb occurs.

View TankGame Repository on GitHub

2. Goomba Dodge & Score

OOP Implementation & Logic:

This interactive game leverages inheritance and custom classes to drive its core mechanics. The central character inherits behavior from a generic Sprite superclass, allowing it to reuse basic movement methods while extending unique properties. User interaction captures movement to navigate the environment. The program features an active scoring system updated via methods whenever a target is successfully interacted with. The visual state highlights custom graphics rendered dynamically onto a solid blue background canvas array.

View Goomba Game Repository on GitHub

3. Digital Etch-A-Sketch & UI Color Palette

OOP Implementation & Logic:

This project focuses heavily on user interface design, utilizing a digital hardware simulation combined with a hex color palette manager. The system uses arrays to store preset hex values (such as #007DEB and #1800EB) which are fed into a constructor to dynamically generate color selection blocks. Through polymorphism, various UI component classes respond differently to click events, allowing seamless color switching or screen clearing, mimicking the classic mechanics of an interactive Etch-A-Sketch drawing board.
